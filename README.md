# 图序 · 景观施工图工作台（本地版）

面向景观园建施工图设计师的本地 AI 工作台：查规范条文、管理大样/材料、生成设计说明、
图纸校对，并支持**直接上传 DWG 图纸提取文字**用于核对。所有数据保存在本机，可完全离线使用。

## 功能

- **查规范**：三模式（综合 / 规范检索 / AI 问答）对话式查条文，答案强制带出处，检索不到明说"未收录"（不编造）
- **本地四库**：图集条文库 / 大样库 / 材料价表库 / 说明模板库（JSONL 存储，随用随录）
- **DWG 直读**：上传 DWG → 本地转换解析 → 提取全部文字标注（穿透块/嵌套块/动态块，中文大字体自动解码）→ 一键送图纸校对
- **说明生成**：模板 + 参数本地填充，零模型成本出初稿
- **图纸校对**：粘贴/提取图纸文字 → 模型对照条文库逐条核对硬指标
- **AI 问答页**：独立对话页，带历史对话（本地浏览器存储）与复制/重新生成/反馈操作
- **安全红线**：涉密关键词（图纸/甲方/工程名称…）发送云端模型前必须用户确认；读写路径白名单；交付物只写 output/ 且禁覆盖

## 快速开始

```bash
pip install -r requirements.txt          # Python 3.10+
cp .env.example .env                     # 填入模型 API key（DeepSeek，可换源）
python webui.py                          # 打开 http://127.0.0.1:8620
```

Mac 也可双击「启动界面.command」。CLI 入口：`python main.py`。

## DWG 能力说明（重要）

DWG 解析依赖两个外部二进制（**不入库**，按说明自行构建/下载）：

| 组件 | 用途 | 获取 |
|---|---|---|
| ODA File Converter | DWG→DXF 转换（文字提取链路） | 免费下载，按 `vendor/oda/README.md` 放入 |
| go-cad | 整图预览渲染（几何渲染优） | 执行 `vendor/gocad/build.sh` 编译 |

两者都缺时 DWG 选项会提示"另存为 DXF 后上传"，其余功能不受影响。
已知边界：天正/探索者等自定义 SHX 字体的私有编码（`\M+5XXXX`）需字体映射文件才能解码；
天正代理几何对象不可读。全部转换在本机完成，图纸数据不上传任何云端。

## 架构

```
webui.py (FastAPI) + web/index.html 单页前端   ← 交互层
harness.py      单一 Agent 循环（≤20 轮，工具调用/自纠）
tools.py        12 个工具：知识库/文件/记忆/计划
tools_cad.py    DWG 适配层（ODA + ezdxf，唯一调用点，可开关回退）
kb.py memory.py plans.py  数据层（JSONL / Markdown / JSON）
llm.py          Anthropic 兼容端点（默认 DeepSeek，.env 可换源）
config.py       路径白名单 / 涉密红线 / 配置开关
```
